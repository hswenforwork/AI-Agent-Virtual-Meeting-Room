# 階段 7：最終驗收與交付

## 目標
確認整個系統真的堪用，交給使用者一份清楚的總結——包含「自己到設定頁輸入 API key」這個開始使用前的
最後一步（BYOK 上線後這是每個使用者自己要做的事，不是部署者的責任）。

## 最終檢查

再查一次三個 GitHub Actions（`check`／`deploy-pages`／`deploy-functions`）都是最新一次成功，網站打得開、能註冊登入。
工作型代理跟 Claude／GPT／Gemini 聊天都要等使用者自己輸入 API key 之後才能實測，不是部署階段能驗證的事，
交付總結裡講清楚接下來要做什麼即可，不用在這裡卡住等使用者測試。

## 交付總結（範例，依實際完成狀況調整）

> 🎉 部署完成！這是你自己的一份「AI 協作室」：
>
> - 網站：`<pages_url>`
> - GitHub 專案：`https://github.com/<target_owner>/<target_repo>`
> - Supabase 專案：`<project_url>`（管理後台在 supabase.com/dashboard）
>
> 打開網站、註冊或用訪客身分登入後，還有最後一步：右上角「設定」頁輸入你自己的 Anthropic／OpenAI／Google
> API key（哪個供應商都可以，先設一個就能開始聊天），設定好對應的代理就能點名使用；工作型代理（任務卡片
> 的「開始執行」）用的也是你自己在這裡設定的 Anthropic key，第一次用時系統會自動幫你準備好背後需要的環境，
> 不需要額外操作{{；工作型代理如果要能直接修改這個專案的原始碼，需要 Phase 6 那組 GitHub token，視你當時是否提供}}。
>
> 之後想再改這個專案（例如加功能、換設計），直接在這個對話裡跟我說就可以，不需要重新跑一次這個部署流程。

## 完成判斷
使用者收到清楚的總結，知道網站在哪裡、接下來要做的最後一步（設定 API key）是什麼。到這裡整個 Skill 結束。
